# Ansible Automation Portfolio

Repository ini berisi catatan pembelajaran pribadi dari **Freecourse Automation With Ansible oleh Adinusa**.

Dokumentasi disusun berdasarkan materi pembelajaran dan praktikum (Lab) yang dipelajari, kemudian dikembangkan menjadi catatan teknis berbahasa Indonesia untuk membantu memahami konsep, penggunaan perintah, konfigurasi, serta penerapan Ansible dalam otomasi administrasi sistem.

## Tujuan

- Mendokumentasikan proses belajar Ansible secara terstruktur.
- Memahami konsep dan mekanisme kerja Ansible, bukan sekadar menghafal perintah.
- Menyimpan catatan praktikum agar mudah dipelajari dan dipraktikkan kembali.
- Menjadi referensi pribadi untuk pembelajaran Linux System Administration dan IT Automation.

## Ruang Lingkup

Repository ini dikembangkan secara bertahap mengikuti materi dan praktikum yang dipelajari. Konten akan terus diperbarui seiring bertambahnya pemahaman dan dokumentasi.

## Sumber Pembelajaran

- **Penyedia materi:** Adinusa
- **Program:** Freecourse Automation With Ansible

Penjelasan tambahan dapat disertakan untuk memperjelas konsep teknis, memberikan konteks, atau membantu proses troubleshooting.
